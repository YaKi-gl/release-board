# Release Board

Трекер релизов для небольшой продуктовой команды: календарь выкладок, стадии релиза и чек-лист готовности.

Проект вырос из моей работы релиз-менеджером во внутреннем сервисе смен и зарплат для сети кофеен. Там релизы планировались в Jira и Confluence, а общий статус «что и когда едет в прод» приходилось собирать вручную. Release Board сводит его на одну страницу.

## Возможности

- **Сводка**: следующий релиз, число релизов в работе, выкачено за месяц, доля откатов.
- **Конвейер стадий**: План → Разработка → Тестирование → В проде → Откат. Работает как фильтр и как переключатель стадии.
- **Чек-лист готовности** для каждого релиза: задачи в Jira, регресс QA, миграции БД, release notes, план отката, предупреждение поддержки. Прогресс виден в списке.
- Создание, редактирование и удаление релизов с подтверждением.
- Светлая и тёмная тема, адаптивная вёрстка под телефон.

## Стек

Один файл `index.html`: HTML, CSS и чистый JavaScript без фреймворков и сборки.
Данные хранятся в `localStorage` браузера. В облачной версии (Claude Artifacts) используется общая база документов с синхронизацией между пользователями в реальном времени.

## Запуск

Откройте `index.html` в браузере. Для публикации подойдёт GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

Проект собран в формате вайбкодинга: я описывал задачу и требования, проверял результат и дорабатывал с ИИ-ассистентом (Claude). Продуктовая часть моя: стадии, чек-лист и метрики взяты из реального процесса релизов.
